# UR3_RG2_rosbridge

## Dangerous things
- self-collision
- cable on top can be overextended   

## Process
- sign with QR code→ powerapp, borrowing   
- get key   
- in drawer, connect cables, hide cable under trolley   
- turn on power
- in back door of the UR3 platform - get touch screen → turn on the robot
- Set IP from computer as static IP to be in the same subnet
- ping the IP of the robot
- Power off on tablet → ON → START → EXIT
- Installation → Tool/IO → change User to OnRobot   
- Can use the `move` tab / if in `local` can press the black button and move the arm by hand if needed
- Move from local to Remote to control it from the laptop   
- Use the Git + toolbox to work on the UR3   

For camera calibration to end effector/base of robot (hand-to-eye) → use an ArUco marker on the end effector
